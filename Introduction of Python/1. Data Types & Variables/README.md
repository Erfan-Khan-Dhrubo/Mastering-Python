# 📘 Introduction of Python

This repository contains multiple Python files, each focusing on a specific core concept of the Python programming language.

---

## 📄 Data Types and Variables

This file covers:
- Integer data type
- Float data type
- String data type
- Boolean data type
- NoneType
- Using the `type()` function to check variable data types
- Printing values along with their types

---

## 📄 Operators

This file covers:
- Arithmetic operators (`+`, `-`, `*`, `/`, `//`, `%`, `**`)
- Assignment operators (`=`, `+=`, `-=`, `*=`, `/=`)
- Comparison operators (`==`, `!=`, `>`, `<`, `>=`, `<=`)
- Logical operators (`and`, `or`, `not`)
- Identity operators (`is`, `is not`)
- Membership operators (`in`, `not in`)
- Bitwise operators (`&`, `|`, `^`, `~`, `<<`, `>>`)

---

## 📄 String Methods

This file covers:
- String length using `len()`
- String indexing
- String slicing (positive and negative)
- Reverse strings using slicing
- Escape sequences (`\n`, `\t`, `\"`)
- Common string methods:
  - `strip()`
  - `upper()`
  - `lower()`
  - `title()`
  - `find()`
  - `replace()`
- Basic number functions:
  - `round()`
  - `abs()`

## 📄 Math Module

This file covers:
- Importing the `math` module
- Square root calculation using `math.sqrt()`
- Rounding numbers using `math.ceil()` and `math.floor()`
- Power calculation using `math.pow()`
- Factorial calculation using `math.factorial()`
- Mathematical constants (`math.pi`, `math.e`)
- Trigonometric functions (`sin`, `cos`, `tan`)
- Logarithmic functions (`log`, `log10`)
- Degree to radian and radian to degree conversion
- Absolute value using `math.fabs()`
- Integer square root using `math.isqrt()`
