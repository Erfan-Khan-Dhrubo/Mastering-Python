# 📘 Control Flow

This folder contains Python examples that demonstrate **conditional statements and loops**, essential for controlling the flow of a program.

---

## 📄 Conditional

This file covers:

- `if` statements for single conditions
- `elif` statements for multiple conditions
- `else` for default actions
- Nested `if` statements
- Combining multiple conditions (e.g., marks and attendance)
- Decision-making logic in Python programs

---

## 📄 Loops

This file covers:

- `for` loops for iterating over lists and sequences
- `for` loops with `range()`:
  - `range(end)`
  - `range(start, end)`
  - `range(start, end, step)`
- `while` loops for condition-based iteration
- Loop control statements:
  - `break` to exit a loop
  - `continue` to skip an iteration
  - `pass` as a placeholder statement
